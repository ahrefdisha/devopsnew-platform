# ACKO Platform & Infrastructure - Automated CI/CD Pipeline

A robust CI/CD pipeline built using **GitHub Actions** and **Docker** to automate unit testing, static code quality checks (linting), and containerization.

## Tech Stack
- **CI/CD:** GitHub Actions
- **Containers:** Docker
- **Testing & Quality:** Pytest, Flake8
- **Language:** Python
- **Tools:** Git, Linux CLI
